# Customer Behavior Analysis & Segmentation

## Overview
This project analyzes customer shopping behavior using SQL and Python to uncover spending patterns, category preferences, and discount effectiveness.

## Tech Stack
- Python (Pandas, SQLAlchemy)
- MySQL
- VS Code
- Jupyter Notebook

## Workflow
1. Loaded raw CSV data into Pandas
2. Persisted data into MySQL using SQLAlchemy
3. Performed SQL-based EDA
4. Retrieved cleaned data for analysis and modeling

## Key Insights
- Identified top-performing product categories
- Analyzed spending differences by gender and discounts
- Prepared data for customer segmentation and ML modelling
